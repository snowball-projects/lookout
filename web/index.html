Portfolio / Holdings
On this device

Your data stays here.

Imported files are read on this device. This app does not upload or persist their contents. Reloading clears the workspace.

The built-in example is synthetic. Values describe the supplied snapshot, not live prices. Missing prices stay unknown.

Exposure reports are calculated offline by Moneyprinter. The viewer checks their structure, totals and association with the portfolio; it does not rerun the fund engine or authenticate a report's author.

Holdings and Exposure are available. Allocation, Markets, Derivatives and Strategies are planned pages without calculations in this release.

Prepare an exposure report

Use the local report command with your workspace JSON and an independent Moneyprinter checkout. It writes a new file for import; it never sends portfolio data to this site. 

python3 scripts/create_report.py holdings.json \
  --engine-root ../moneyprinter > report.json

The source README explains setup and the supported input format.
